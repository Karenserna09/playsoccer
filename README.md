# Dashboard de Jugadores - Top Club Soccer

## Descripción
Proyecto realizado en React usando Vite para gestionar jugadores de fútbol con estadísticas en tiempo real, favoritos, búsqueda y paginación.

## Hooks utilizados

### useState
Se utilizó para manejar:
- búsqueda
- favoritos
- modal
- paginación
- modo oscuro
- historial

### useEffect
Se utilizó para:
- debounce
- localStorage
- actualización automática
- limpieza de temporizadores

### useMemo
Se utilizó para optimizar estadísticas y evitar cálculos innecesarios.
